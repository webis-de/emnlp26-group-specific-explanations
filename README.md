# Attribute-based Activation Steering of LLMs for Group-Specific Explanation Generation

The repository contains the source code to reproduce the results of the paper [**"Attribute-based Activation Steering of LLMs for Group-Specific Explanation Generation"**](https://arxiv.org/pdf/2608.29215).

## Usage

The code was written in Python 3.10.13. All dependencies can be installed with:

```bash
python -m pip install -r requirements.txt
```

Unzip the data folder `./code/data.zip` into `./code/data`. Follow the instructions in [OpenFActScore](https://github.com/lflage/OpenFActScore) to install the FActScore package. Save the downloaded data in `./code/data/factscore/`.

## Code

Navigate to the `code` directory:

```bash
cd code
```



Start the script with the following command:

```bash
python main.py --enable-llm
```

Without the `--enable-llm` parameter, all tasks that require ML models will not be executed.

All configuration parameters can be changed inside the `config_new_prompts.py` file. The script will check if a task has already been executed and will not execute anything twice. All generated data is saved in a SQLite file `data.sqlite`. Trained models are saved in the `models` folder. Results are saved in the `results` folder.

## Data

Navigate to the `data_exemplary` directory:

```bash
cd data_exemplary
```

Since the database file `data.sqlite` is > 100 GB in size (including all generated explanations for the validation and test questions of all LLMs), only a subset of the explanations generated by Qwen 7B is uploaded.

This subset includes explanations for the 600 ELI5 test questions and 97 science questions. The data is available in the following file:

`data_Qwen_7B_test_questions.json`

The Jupyter notebook `get_samples.ipynb` can import the JSON file and process it.
